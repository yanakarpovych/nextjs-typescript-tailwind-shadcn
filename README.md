# Support Me

An employee management dashboard built with Next.js and TypeScript, featuring an overview of employee and team statistics, an employees page with a data table, and authentication forms with client-side validation.

## Demo

[Live Demo](https://support-3m2xnwrtz-yana-39dd.vercel.app/)

## Features

- View the dashboard overview with employee and team statistics
- Explore employee statistics and work location trends
- View team distribution charts and support ticket statistics
- Browse employees in a data table
- Navigate between dashboard sections
- Sign in and sign up through interactive forms
- Validate form inputs using React Hook Form and Zod
- Switch between light and dark themes
- Responsive user interface

## Getting Started

Clone the repository:

```bash
git clone https://github.com/yanakarpovych/nextjs-typescript-tailwind-shadcn.git
```

Navigate to the project directory:

```bash
cd nextjs-typescript-tailwind-shadcn
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To run ESLint:

```bash
npm run lint
```

To create a production build:

```bash
npm run build
```

To start the production server locally:

```bash
npm start
```

## Notes

This project is a frontend demonstration. Authentication forms use client-side validation only. No backend authentication, database integration, or persistent employee data storage is implemented.
